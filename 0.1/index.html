Overview

go-theca documentation

go-theca holds Theca, an encrypted container format (a file or a block device that holds a volume) written in pure Go with CGO_ENABLED=0. The goal is a format that is better than the state of the art in composition, that is, in how known, analysed primitives are put together, while inventing no primitive and no mode.

Theca v0.7.0 is released (v0.2.0 to v0.7.0, 2026-11-16 and 2026-11-17); see its CHANGELOG. The format may still change before v1 (below v1, a breaking change bumps the minor version). Theca has a library and a command line (create, info, verify, import, export, enroll-key, serve). Since v0.2.0 it can serve the files inside a container over SMB on loopback and mount them in the file manager; since v0.3.0 that is a library package, share, and the go-theca/gui desktop window (v0.2.0) uses it. A container opens with a password, a recovery code, or a FIDO2 key paired with one of them. This site describes theca tag v0.7.0 and gui tag v0.2.0.
